# Verkefni 5 — Gæðakröfur, árekstrar og viðskiptareglur (HBV301G)

## Kerfi og höfundar

- **Heiti kerfis:** Vaktaskiptakerfi
- **Hópmeðlimir:** Edil Inga Kristjánsdóttir og Gabríel Orri Karlsson

### Stutt lýsing á kerfinu

Vaktaskiptakerfið er hugbúnaðarkerfi sem auðveldar starfsmönnum að skipuleggja og framkvæma vaktaskipti. Starfsmenn geta skoðað tiltækar vaktir, sent beiðnir um vaktaskipti og brugðist við beiðnum annarra starfsmanna.

Kerfið er ætlað starfsmönnum og stjórnendum og hefur það að markmiði að einfalda utanumhald vaktaskipta, draga úr handvirkri vinnu og bæta yfirsýn yfir vaktaskipulag.

Verkefnið byggir á vaktaskiptakerfinu sem var skilgreint í fyrri verkefnum námskeiðsins. Í þessu verkefni er lögð áhersla á gæðakröfur, mögulega árekstra þeirra og viðskiptareglur sem hafa áhrif á virkni kerfisins.

### Forsendur

Gæðakröfur verkefnisins byggja á skilgreindum prófunaraðstæðum og mælanlegum viðmiðum. Viðmiðin eru tillögur fyrir verkefnið og hafa ekki verið staðfest af hagsmunaaðilum.
